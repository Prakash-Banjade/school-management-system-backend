# School Management System Backend

## Technologies Used

- [NestJS](https://nestjs.com/)
- [TypeORM](https://typeorm.io/)
- [Fastify](https://fastify.dev/)
- [MySQL](https://dev.mysql.com/)

## Features

1. User Management
2. Roles & Permissions
3. Student, Teacher, Staff Management
4. Finance Module (Salary, Payments, etc.)
